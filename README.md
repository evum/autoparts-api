# Autoparts

React-приложение для поиска производителей автозапчастей по артикулу.
Стек: JavaScript, React, Redux Toolkit, Bootstrap, Vite. Node.js 22.12+ или 24+.

## Запуск

```powershell
npm ci
Copy-Item .env.example .env
```

Укажите в `.env` значение `FAVORIT_API_KEY` — клиентский ключ из личного кабинета Фаворит.
Файл `.env` исключён из Git. После изменения ключа перезапустите сервер.

```powershell
npm run dev
```

Откройте адрес, показанный Vite (обычно http://127.0.0.1:5173).
Без ключа интерфейс работает, но при поиске покажет сообщение о необходимости настройки.

## Первый этап

- Поиск автоматически запускается через 500 мс после последнего изменения артикула.
- Пустой ввод не отправляет запрос. Изменение артикула отменяет предыдущий запрос и сбрасывает выбор.
- Производители извлекаются из `goods[].brand`, пустые значения и повторения исключаются.
- Доступны состояния загрузки, пустого ответа и ошибки, повторный запрос и выбор бренда.
- Выбранный бренд и артикул хранятся в Redux. Получение аналогов (второй этап) пока не реализовано.

## API

[Документация Фаворит](https://lk.favorit-parts.ru/static/wsprice.pdf).
Браузер обращается к `/api/manufacturers?number=...`. Серверная middleware Vite
добавляет ключ и отправляет GET на `https://api.favorit-parts.ru/hs/hsprice/`
с параметрами `key` и `number`, без `brand` и `analogues`.
Спецсимволы кодируются через `URLSearchParams`. Тайм-аут внешнего запроса — 12 секунд.
Ключ не включается в клиентскую сборку и не возвращается браузеру.

Middleware подключена к `npm run dev` и `npm run preview`. Для размещения `dist`
на статическом хостинге потребуется отдельный серверный маршрут `/api/manufacturers`:
одной клиентской сборки для доступа к API недостаточно.
